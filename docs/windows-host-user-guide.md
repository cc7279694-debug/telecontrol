# Codex Remote Host 使用说明

这是一份面向第一次使用的 Windows 说明。Codex Remote Host 安装在电脑上，安卓手机通过网络向它发送控制指令。

## 使用前准备

- Windows 10 或 Windows 11，64 位。
- 电脑需要保持开机、联网，并保持当前 Windows 用户处于登录状态。
- 电脑上原有的 Codex 登录状态和 OpenAI 代理设置继续使用，不需要重新配置。
- 手机使用现代 Android Chrome 浏览器打开远程控制网页。

本应用不会修改 VPN、代理、路由器、防火墙、睡眠或休眠设置，也不会安装 Windows 服务。

## 安装

这是当前用户安装包，只会安装到当前 Windows 用户，不需要管理员权限。私人测试包可能没有代码签名，Windows SmartScreen 可能显示警告。

注意：当前 5C 包使用本机回环地址，仅用于本机验收，不能直接让安卓手机远程连接。安卓远程控制需要后续完成 5D 云端配置和真机验收。

打开安装包前，请先向发布者确认版本和 SHA-256 校验值。可以在 PowerShell 中查看校验值：

```powershell
Get-FileHash .\Codex-Remote-Host-版本-Windows-x64.exe -Algorithm SHA256
```

如果校验值不一致，不要打开安装包。没有代码签名的私人测试包不等同于正式公开发行版。

## 第一次启动

1. 启动 Codex Remote Host。
2. 输入已经注册的邮箱并获取一次性验证码。
3. 登录后，在“本机授权”区域添加允许 Codex 使用的项目目录。
4. 在“添加安卓设备”区域生成一次性配对码。
5. 在安卓手机打开远程控制网页，登录同一账号并输入配对码。
6. 配对完成后，保持 Host 运行，手机即可连接这台电脑。

手机只提交项目的授权 ID，不直接提交 Windows 路径。电脑端会再次检查目录是否属于已授权范围。

## 日常使用

- 托盘图标会显示 Host 状态，可以从托盘打开管理窗口、启动或停止 Host、运行 Doctor。
- “开机时启动”只控制当前用户登录后的启动项，不会创建系统服务。
- 停止 Host 前，如果仍有远程任务，应用会要求二次确认。
- 手机断网时不能创建新的远程操作；恢复网络后会重新获取权威状态。
- 电脑端正在运行的 Codex Desktop 任务不会被 Host 接管。

## Doctor 和日志

遇到连接问题时，先在管理窗口运行 Doctor。Doctor 只做检查，不会修改系统设置。

“打开日志目录”用于查看脱敏诊断日志。日志不应包含提示词、代码、命令、Windows 路径、邮箱、Token 或私钥。如果发现疑似敏感内容，请不要继续分享日志文件。

## 卸载和清除数据

默认卸载会保留本机配置，方便重新安装后恢复登录和 Host 设置；不会删除项目目录或 Codex 历史。

如果需要完全清除本机 Host 数据，请先在应用内执行“清除本机数据”并完成二次确认，再卸载。这个操作只清除 Host 自己的配置和凭据，不删除项目文件，也不删除 Codex 历史。

## 常见问题

### 手机连接不上

确认电脑仍开机联网、Host 正在运行、手机和电脑使用同一账号，并重新检查配对是否已经过期。必要时重新生成配对码。

### 为什么不需要 VPN

手机和 Windows Host 都通过云端中转连接，不要求手机直接访问电脑，也不要求打开路由器端口。电脑仍然必须联网。

### 为什么 Windows 显示安全警告

私人测试包通常没有商业代码签名。先核对发布者提供的 SHA-256，再决定是否继续；不要运行来源不明或校验值不一致的安装包。
