# Android PWA 3C 控制台设计说明

## 目标

在已经通过验收的 3B 登录、设备身份、配对和加密通信层之上，完成安卓优先的 Codex Remote 控制台。用户打开 PWA 后，在一个首页中查看唯一 Windows Host、选择授权项目、浏览任务；进入任务后以聊天式界面读取历史、发送或追加指令、处理审批并停止运行。

## 范围

本阶段包含：

- 单 Host 首页、授权项目选择和任务列表；
- 任务读取、恢复、新建和分页；
- 聊天式时间线、流式输出、运行状态和错误状态；
- `turn.start`、`turn.steer`、`turn.interrupt` 和 `approval.respond` 控件；
- 安卓 PWA Manifest、安装引导、离线壳和非敏感状态提示；
- 360 px、390 px 和桌面宽度的自动化浏览器验收。

本阶段不包含：

- Vercel Preview、正式 Supabase 项目或生产发布；
- Web Push 和锁屏通知；
- Windows 安装包、开机启动或 DPAPI 永久凭据；
- Git、Diff、文件浏览、语音、图片和多用户功能；
- 接管 Codex Desktop 正在执行的任务。

## 已选择的产品结构

### 单屏首页

`/hosts` 是登录后的主页面，不增加“电脑 → 项目 → 任务”的三级导航。页面顶部显示唯一 Windows Host 的连接状态；中部选择授权项目；下方直接显示该项目的任务列表。页面记住该 Host 上次选择的 `workspaceId`，但不持久化本机路径或项目内容。

无设备身份、无有效配对或配对已撤销时，页面引导到 `/pair`。Host 离线时仍显示最后一次非敏感状态和已有列表，但禁用刷新以外的远程操作。

### 聊天式任务页

`/hosts/[hostId]/threads/[threadId]` 显示结构化时间线：用户指令、Codex 回复、推理摘要、命令或文件变更状态使用不同的可访问样式。技术细节默认收起，不渲染未知原始 JSON。

底部输入区固定在安全区上方：空闲任务发送 `turn.start`；本 Host 拥有的运行中任务发送 `turn.steer`；只读、离线或未连接时禁用。停止操作必须二次确认后发送 `turn.interrupt`。

### 审批

审批卡片只显示 Host 已脱敏的标题和说明，只渲染 `allowedDecisions` 中实际存在的决定。审批事件必须携带 `threadId` 和 `turnId`，以免显示到错误任务。提交后立即锁定卡片；收到终态、切换任务或状态已无法确认时标记失效并请求权威快照。3C 不自行扩大目录权限，也不展示原始命令、路径或参数。

## 状态与数据流

1. `RemoteSessionProvider` 验证当前账号，读取 IndexedDB 中的设备身份，再通过 RLS 查询该设备唯一的有效 Host 链接。
2. Provider 创建现有 `BrowserRemoteClient`，并交给现有 `RemoteProvider` 作为唯一的连接所有者；`RemoteProvider` 连接私有 `host:<hostId>` 频道并调用 `requestSnapshotAndWait()` 获取第一份权威 Host 快照。
3. 首页从快照读取 Host 和授权项目；项目改变时发送新的 `thread.list` 命令。每次用户操作默认生成新的 `messageId` 和幂等键；只有同一次明确重试才复用调用方提供的幂等键。
4. 新建、恢复或读取任务时，页面先订阅事件，再发送命令，并仅接受 `requestMessageId` 与命令回执匹配的 `thread.snapshot`。
5. `RemoteProvider` 将快照、任务列表、流式增量、运行状态、审批和命令回执归并到前端状态。序号重复时忽略；序号缺口或重新联网时请求权威快照。
6. 页面卸载时取消订阅并断开频道，不在浏览器缓存中写入提示词、回复、代码、路径或密文信封。

## 失败与恢复

- 首次连接失败：显示可重试错误，不把“已登录”误报为“电脑在线”。
- Host 离线：任务列表保持只读，所有会产生命令的按钮禁用。
- 命令提交失败：保留输入文本，让用户手动重试；新重试使用新的命令 ID，避免旧结果被误认。
- 流式序号缺口：停止拼接缺失内容并请求快照。
- 页面恢复可见或网络恢复：复用 3B 的重连逻辑，再请求权威状态。
- 外部运行任务：显示“电脑端正在运行”，禁用追加、停止和审批。
- 协议或设备撤销错误：退出远程会话并引导重新配对，不循环重试。

## PWA 与缓存边界

- Manifest 使用简体中文名称、`standalone` 展示模式和 192/512/maskable 图标。
- Service Worker 只缓存版本化静态资源、图标和 `/offline`。
- `/hosts`、任务页、Supabase、Auth、Realtime、API、命令信封一律 network-only，不进入 Cache Storage。
- 离线页最多读取 `{ online, observedAt, lastTurnStatus }`，不保存 Host 名、工作区名、任务标题或正文。
- 未触发浏览器安装事件时仅展示手动“添加到主屏幕”说明，不阻塞网页使用。

## UI 与可访问性

- 简体中文，移动端优先，灰阶现代界面；支持浅色和深色。
- 最小触控目标 44×44 px，明显焦点环，状态不仅依赖颜色表达。
- 360×800、390×844 和 1280×800 均无横向溢出。
- 时间线仅在用户已接近底部时自动滚动；用户向上阅读时保持位置。
- 输入区使用 `100dvh`、safe-area padding 和可缩小布局，软键盘出现时仍可操作。

## 验收边界

3C 在本地通过以下闭环后完成：本地 OTP 登录、现有设备配对、Host 快照、项目选择、任务列表/读取/新建/恢复、发送/追加、流式输出、审批、停止、离线禁用和 PWA 安装信息。所有单元、数据库、构建和浏览器测试通过，构建产物不包含服务端密钥、测试账号、Windows 路径或私钥字段。

真实 Vercel、Hosted Supabase、安卓手机流量时延、锁屏通知和 Windows 安装包继续作为后续独立授权阶段。
